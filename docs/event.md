## Judging rubric (five dimensions, scored independently)

1. **Problem relevance and real-world value.** A real problem, a defined user,
   value stated in one or two sentences.
2. **Technical execution.** Running software end to end; logic beyond
   prompting; edge and failure cases handled. Penalized: mocked flows,
   hard-coded responses, manual steps.
3. **Architecture and system design.** Sensible separation; AI used where it
   adds leverage; awareness of latency, cost, and scaling.
4. **Production readiness.** Could deploy with incremental work; knows its
   limits; realistic scope for the sprint.
5. **Vision and continuation.** A believable roadmap; feels like the first
   version of something real.

Overall principle: working systems over presentations, clarity over
complexity, usefulness over novelty.
